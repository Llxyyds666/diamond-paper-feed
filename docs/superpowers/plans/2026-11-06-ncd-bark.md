# NCD/UNCD Bark Implementation Plan

**Goal:** Push every newly discovered DeepSeek-confirmed NCD/UNCD paper through Bark.

**Architecture:** Add a separate durable watcher and workflow consuming state.json. Keep collection, broad AI publication and device RSS APIs intact. Persist outbox before delivery and accepted receipts afterward.

**Tech Stack:** Python 3.11+, pytest, existing DeepSeekClient/AbstractEnricher/Bark client, GitHub Actions.

## Constraints

- Full original abstracts; no daily NCD candidate/request ceiling.
- Include all research directions and both NCD and UNCD; no ranking cutoff.
- Initialize existing papers as baseline, then process new discoveries and retry failures.
- Secrets remain environment variables; no secrets in state or logs.
- Reuse the clean linked checkout; preserve the unrelated dirty deployed-verification checkout.
